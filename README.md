# BEWEX

![BEWEX Monitor](assets/screenshots/monitor-preview.png)

현장에 흩어진 카메라 세 대 — 휴대폰 2대와 PC 화면 1개 — 를 관제 화면 하나로 모아 보여주는 시스템입니다.

## 무엇을 할 수 있나

- **현장 인력은 휴대폰만 있으면 됩니다.** 앱을 깔거나 계정을 만들 필요 없이, QR코드를 찍고 방송 시작 버튼만 누르면 관제 화면에 그 폰 카메라가 뜹니다.
- **PC 화면도 함께 내보낼 수 있습니다.** 지도 프로그램이나 계측 화면처럼, 보여주고 싶은 창 하나를 골라 같이 송출합니다.
- **관제석에서는 세 화면을 동시에 봅니다.** 휴대폰 2대 + PC 화면 1개가 한 화면에 고정 배치됩니다.
- **연결이 불안정해도 화면이 끊기지 않습니다.** 네트워크 상태가 나빠지면 화질을 낮춰서라도 계속 이어지도록 자동으로 전환됩니다.

## 왜 만들었나

현장 요원이 촬영하는 화면과 PC의 지상국 소프트웨어를 관제석에서 동시에 봐야 하는데, 기존에는 서로 다른 화면 공유 툴을 따로따로 띄워 써야 했습니다. 연결이 끊겨도 어디서 문제가 생겼는지 알기 어려웠고, 네트워크가 막히면 화면이 그냥 멈췄습니다.

이 문제를 해결하려고 처음부터 직접 만들었습니다.
