# BEWEX

![BEWEX Monitor](assets/screenshots/monitor-preview.png)

현장에 흩어진 카메라 세 대 — 휴대폰 2대와 PC 화면 1개 — 를 관제 화면 하나로 모아 보여줍니다.

| 항목 | 내용 |
|---|---|
| 소스 | 휴대폰 카메라 2대 + PC 창(또는 전체 화면) 1개 |
| 전송 | WebRTC P2P — 막히면 서버 릴레이로 자동 전환 |
| 서버 | 라즈베리파이 상시 구동 |

---

## 1. 휴대폰은 QR코드를 찍고 방송 시작만 누릅니다

앱 설치도 계정도 필요 없습니다. QR코드를 찍으면 그 즉시 관제 화면에 카메라가 뜹니다.

---

## 2. PC 화면도 함께 내보냅니다

지도 프로그램이나 계측 화면처럼, 보여주고 싶은 창 하나를 골라 세 번째 자리로 송출합니다.

---

## 3. 관제석은 세 화면을 한 번에 봅니다

휴대폰 2대와 PC 화면이 한 화면에 고정 배치됩니다. 연결 상태와 화질도 함께 표시됩니다.

---

## 4. 네트워크가 막히면 알아서 우회합니다

연결이 원활하지 않으면 화질을 낮춰서라도 화면이 끊기지 않게 전환합니다.

---

## 왜 만들었나

현장 요원이 촬영하는 화면과 PC의 지상국 소프트웨어를 관제석에서 동시에 봐야 하는데, 기존에는 서로 다른 화면 공유 툴을 따로 띄워 써야 했습니다. 연결이 끊겨도 원인을 알기 어려웠고, 네트워크가 막히면 화면이 그냥 멈췄습니다. 이 문제를 해결하려고 처음부터 직접 만들었습니다.
